Importa estratto conto

Carica il file CSV, Excel o PDF scaricato da Intesa Sanpaolo o Revolut. Il PDF è letto a testo: se una riga non viene capita, controlla l'elenco prima di importare. L'app ti propone le categorie in base alle tue spese precedenti: tu confermi o cambi. Il file resta sul tuo telefono, non viene inviato a nessun servizio.

Nuovo movimento

Puoi scrivere il nome di un conto mai usato prima: verrà creato automaticamente con il primo movimento che salvi.
Puoi scrivere il nome di una categoria mai usata prima: verrà creata automaticamente con il primo movimento che salvi (ricordati di indicare anche la Macro-categoria qui sotto).
